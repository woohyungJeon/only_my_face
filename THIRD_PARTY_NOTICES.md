# Third-party notices

Only My Face bundles the following OpenCV Zoo model files.

- YuNet face detector (`assets/models/yunet/face_detection_yunet_2023mar.onnx`), MIT License. The full license text is distributed beside the model at `assets/models/yunet/LICENSE`.
- MP-PersonDet person detector (`assets/models/persondet/person_detection_mediapipe_2023mar.onnx` and `anchors.csv`), Apache License 2.0. It is used as a broad upper-person privacy safety net when a profile or back-of-head has no reliable face box. The full license text is distributed at `assets/models/persondet/LICENSE`.
- SFace face recognizer (`assets/models/sface/face_recognition_sface_2021dec.onnx`), Apache License 2.0. The full license text is distributed beside the model at `assets/models/sface/LICENSE`.
