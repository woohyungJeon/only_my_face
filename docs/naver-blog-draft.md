# (블로그 소개글 초안) Only My Face — 사진 속 얼굴 자동 모자이크 프로그램

> 네이버 블로그에 붙여넣기용 초안입니다. `[다운로드 링크]` 부분만 실제 GitHub Release 주소로 바꿔주세요.

---

## 블로그에 사진 올릴 때, 얼굴 모자이크 일일이 하기 귀찮으셨죠?

여행 사진, 모임 사진, 아이 사진… 블로그에 올리고 싶은데 **지나가는 사람들 얼굴**까지 하나하나 가리는 게 정말 번거롭습니다.

그래서 만들었습니다. **Only My Face** — 사진을 넣으면 **모든 얼굴을 자동으로 찾아서 모자이크(또는 블러) 처리**해주는 무료 프로그램입니다.

### ✅ 가장 중요한 것 — 사진이 밖으로 안 나갑니다

이 프로그램은 **내 컴퓨터 안에서만** 얼굴을 인식하고 처리합니다. 사진을 인터넷 서버로 보내지 않아요. 개인 사진, 아이 사진도 안심하고 쓰실 수 있습니다.

---

## 주요 기능

- 📸 **여러 장 한 번에** 처리 (드래그로 여러 파일 선택)
- 🧩 **모자이크 / 블러** 선택, 강도·범위 조절
- 👀 **설정 미리보기** — 조절하면 바로 어떤 느낌인지 화면에서 확인
- 🙋 **예외 인물 등록** — "이 사람(나/우리 아이)은 가리지 않기" 지정 가능
- 💾 처리 결과를 원본과 별도 파일로 저장 (`사진이름_mosaic.png`)

## 다운로드 & 설치

1. 아래 링크에서 `OnlyMyFace-Setup.exe`를 내려받으세요.

   👉 **https://github.com/woohyungJeon/onlymyface/releases/latest**

2. 받은 파일을 더블클릭해 설치합니다. (설치 후 바탕화면에 아이콘이 생겨요)

3. 설치·실행 시 **"Windows의 PC 보호"** 파란 창이 뜰 수 있어요. 이건 개인 개발자가 만든 프로그램이라 뜨는 안내이고 바이러스가 아닙니다.
   → **[추가 정보]** 클릭 → **[실행]** 을 눌러주세요.

> 💡 인터넷 연결이나 파이썬 같은 별도 설치는 필요 없습니다. 파일 하나로 바로 실행돼요. (용량은 약 380MB — AI 얼굴 인식 모델이 안에 포함되어 있어서 조금 큽니다.)

---

## 사용법

1. **파일 선택** → 처리할 사진들을 고릅니다. (선택하면 바로 미리보기가 떠요)
2. 효과(모자이크/블러)와 강도를 정합니다. — 화면 위 **설정 미리보기**로 느낌을 확인하세요.
3. **모든 얼굴 가리기** 클릭 → 진행률 바가 차오르고 결과가 나옵니다.
4. **결과 전체 저장** → 저장할 폴더를 고르면 끝!

---

## 참고

- 현재 **Windows 전용**입니다.
- 처음 실행할 때 얼굴 인식 준비로 잠깐 시간이 걸릴 수 있어요.
- 개인·비상업 용도로 자유롭게 쓰세요. (얼굴 인식 모델은 비상업 연구용 라이선스 기반입니다)
- 새 버전이 나오면 프로그램이 알려드립니다. 그때 이 글의 링크에서 다시 받아 설치하시면 됩니다.
